# 🚀 Release Notes - v0.1.0 (Initial & Stabilization)

**Tanggal Rilis:** 16 September 2026  
**Versi:** `0.1.0`  
**Rentang Komit:** `1e24b14` (Initial Commit) s/d `0e848cd`

---

## 📋 Ringkasan Eksekutif

Versi **v0.1.0** menandai rilis inisial publik yang matang untuk **Spark AI Studio**. Dimulai dari prototipe studio generasi gambar untuk OpenAI Images API, proyek ini berkembang secara menyeluruh menjadi platform *private studio* mandiri dengan sistem autentikasi multi-pengguna, isolasi data per akun, manajemen kapasitas disk cerdas, retensi otomatis, serta dukungan *Progressive Web App* (PWA).

---

## 🌟 Fitur Utama & Kemampuan Baru

### 1. 🎨 OpenAI Images Generations & Edits Engine
- **Integrasi OpenAI Images API**:
  - Endpoint Generasi: `POST {base_url}/images/generations`
  - Endpoint Edit: `POST {base_url}/images/edits`
- **Dukungan 4 Model Resmi (Strict Selection)**:
  - `gpt-image-2`
  - `gpt-image-2.5` *(Default)*
  - `gpt-image-2.5-flare`
  - `gpt-image-2.5-sunburst`
- **Pengaturan Ukuran Gambar & Rasio**:
  - Preset rasio bawaan: `auto`, `1:1` (1024x1024), `3:2` (1536x1024), `2:3` (1024x1536), `16:9` (1536x864), `9:16` (864x1536).
  - Skalabilitas Cerdas `(x2)` dan `(:2)` dengan pembulatan kelipatan 16 otomatis dan validasi batas dimensi OpenAI.
  - Mode Custom Resolution dengan validasi kepatuhan real-time.
- **Kualitas Output Adaptif**:
  - Mendukung opsi `auto`, `low`, `medium`, `high`, serta opsi lanjutan `xhigh` dan `max` untuk model seri Sunburst dan Flare.

### 2. ✨ AI Prompt Enhancer
- Menambahkan fitur penyempurna prompt otomatis berbasis kecerdasan buatan (`/api/enhance`).
- Membantu memperkaya deskripsi visual, pencahayaan, komposisi, serta gaya artistik untuk menghasilkan output generasi gambar yang optimal.

### 3. 🖼️ Multi-Layer Image Edits & Input Fidelity
- **Arsitektur Multi-Layer Gambar**: Mendukung pengunggahan `Image 1` hingga `Image N` untuk proses edit berbasis konteks ganda.
- **Dukungan Opsi Input Fidelity**: Memungkinkan pemilihan tingkat ketelitian input gambar (`low` / `high`, default ke `high`).
- **Pengiriman Base64 JSON**: Konversi file gambar otomatis ke format Base64 Data URL tanpa dependensi multipart form-data.
- **Full Session Restore**:
  - Fitur *"Gunakan Ulang Prompt dan Gambar"* untuk memulihkan prompt dan seluruh layer gambar asli kembali ke form editor.
  - Fitur *"Edit Gambar"* (Chain Editing) untuk langsung menjadikan hasil olahan sebelumnya sebagai gambar input dasar berikutnya.

### 4. 🗃️ Riwayat API Terpadu (History), Paginasi & Export Data
- Penyimpanan persisten ke database SQLite lokal (`data/spark_ai_studio.db`).
- Paginasi *server-side* pada riwayat untuk navigasi yang lancar saat data riwayat berjumlah besar.
- Modal detail inspeksi lengkap (status code HTTP, waktu eksekusi, prompt utuh, payload request, dan response JSON).
- Fitur **Export History ke format JSON** yang bersih dan terstruktur.

### 5. 🔐 Multi-User Authentication & Isolasi Pengaturan
- **Studio Privat**: Sistem login dan registrasi berbasis sesi cookie aman (`httpOnly`).
- **Isolasi Pengaturan**: Tabel `app_settings` terikat ke masing-masing pengguna (`user_id`), menjamin API Token, Base URL, dan preferensi model antar pengguna tidak saling bercampur.
- **Manajemen Profil**: Kemampuan memperbarui Nama Tampilan (*Display Name*) dan Mengganti Password langsung dari antarmuka web.
- **Fitur Ekspor & Impor Pengaturan**: Kemudahan mem-backup atau memindahkan konfigurasi studio antar lingkungan via berkas JSON terenkripsi/terstruktur.

### 6. 🧹 Smart Storage Management & Auto-Retention
- **Pembersihan File Sampah (Orphaned Files)**: Pemindaian direktori `/public/uploads/` dengan penghapusan 1-klik terkonfirmasi.
- **Grace Period Protection**: Perlindungan file yang baru diunggah dalam jendela waktu tertentu agar tidak terhapus sebelum disimpan ke riwayat.
- **Auto-Retention Policy**: Kebijakan retensi otomatis untuk membersihkan log riwayat dan berkas gambar lama yang telah melampaui batas retensi secara berkala.

### 7. 📱 PWA (Progressive Web App) & Optimalisasi Tampilan Mobile
- Dukungan PWA lengkap dengan Service Worker, manifest Web App, serta tombol instalasi cepat di antarmuka.
- Tampilan responsif adaptif untuk perangkat mobile dengan penggunaan unit viewport dinamis (`dvh`) pada modal dialog.
- Fallback clipboard untuk lingkungan LAN/HTTP non-HTTPS.

---

## 🛠️ Perbaikan & Optimasi Teknis

- **Sanitasi Payload Riwayat**: Menghilangkan string Base64 gambar duplikat dari kolom riwayat SQLite guna mencegah pembengkakan ukuran file database (*history bloat*).
- **Proteksi Brute-Force**: Penerapan rate limiter cerdas pada endpoint autentikasi guna mencegah eksploitasi CPU starvation.
- **Pembersihan Sesi Orphaned**: Menghapus token sesi kedaluwarsa secara otomatis.
- **Handling File Statis di Lingkungan Produksi**: Penyediaan rute dinamis `/api/uploads/[filename]` agar file yang diunggah saat runtime produksi Next.js dapat diakses tanpa hambatan.
- **Pencegahan Re-render Loop**: Perbaikan bug *stale pagination state* dan optimasi React hook pada antarmuka riwayat.
- **Pencegahan Duplikasi Logout & CSRF**: Menangani event logout ganda dan memastikan request API internal terverifikasi.
