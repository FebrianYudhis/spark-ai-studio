# 🚀 Release Notes - v0.2.0 (Hardening, Kolaborasi & Polish)

**Tanggal Rilis:** 23 September 2026  
**Versi:** `0.2.0`  
**Rentang Komit:** `f00086e` (rilis v0.1.0) s/d `3c7f617`

---

## 📋 Ringkasan Eksekutif

Versi **v0.2.0** adalah rilis penyempurnaan lanjutan atas fondasi v0.1.0. Fokus utama rilis ini ada pada tiga area: **pengerasan keamanan** (kebocoran token, SSRF, validasi konten upload, gate header proxy, sanitasi pesan error), **pengalaman pengguna & developer** (modal inspeksi respons error, modal instalasi PWA multi-platform, tanggal berzona waktu, pembukaan hasil generasi langsung di tab baru), serta **kolaborasi konfigurasi antar pengguna** (berbagi snapshot pengaturan dengan alur pending/accept/reject).

Secara arsitektural, rilis ini juga merapikan kontrak API dan menghapus kode mati: helper bersama dipusatkan di `src/lib/utils.ts`, tabel `app_settings` dihapus dan digantikan `user_settings`, serta kontrak error distandarkan pada satu field `error`.

---

## 🌟 Fitur Utama & Kemampuan Baru

### 1. 🔎 Modal Inspeksi Detail Respons Error
- Modal baru `ErrorDetailModal.tsx` untuk memeriksa kegagalan request pada tab **Generation** dan **Edit**.
- Menampilkan **status HTTP**, **endpoint**, **payload request**, dan **respons mentah** (JSON maupun HTML).
- **Deteksi HTML error page** (mis. halaman error dari reverse-proxy/gateway) agar isi non-JSON tetap terbaca.
- Aksi **salin** ke clipboard, serta **truncation payload base64** agar modal tetap ringan.

### 2. 🤝 Berbagi Konfigurasi Antar Pengguna
- Endpoint baru `POST/GET/DELETE /api/config/share` untuk mengirim snapshot pengaturan ke username lain.
- Alur **pending → accept/reject**, didukung tabel baru `config_shares` (dengan relasi ke pengguna asal dan tujuan).
- **Rate limit per-user dan per-IP** khusus endpoint share untuk mencegah penyalahgunaan.
- Pesan **generik anti-enumerasi** sehingga keberadaan username lain tidak dapat ditebak dari respons.

### 3. 📱 Modal Instalasi PWA Revamp
- `InstallPwaButton.tsx` ditulis ulang menggunakan **React Portal** agar modal terpusat dan tidak terpotong konteks tumpukan (stacking context) induknya.
- Tab panduan per platform: **Android**, **iPhone**, dan **Komputer**.
- Tombol **native install prompt** bila browser mendukung, plus ringkasan keuntungan PWA.

### 4. 🌱 Seed Konfigurasi via `.env` & Sinkronisasi Settings Live
- Akun baru dapat di-seed dengan konfigurasi default dari `.env` (`AI_BASE_URL`, `AI_GENERATIONS_MODEL`, `AI_EDITS_MODEL`, `AI_ENHANCER_*`) melalui `.env.example`. Token API **sengaja tidak** di-seed agar tetap terisolasi per pengguna.
- Settings disinkronkan **live saat window kembali fokus**, sehingga perubahan konfigurasi antar tab/perangkat tetap konsisten.

### 5. 🕓 Tanggal Berzona Waktu yang Dapat Dikonfigurasi
- Tampilan tanggal kini mengikuti `NEXT_PUBLIC_APP_TIMEZONE` (default `Asia/Jakarta`).
- Format tanggal dibuat aman terhadap **"Invalid Date" di Safari/iOS** (timestamp SQLite tanpa penanda zona diperlakukan sebagai UTC).

## 🛠️ Perbaikan & Optimasi Teknis

- **Anti-kebocoran token (`5c85238`)**: field `rawToken`/`enhancerToken` dihapus dari respons API dan ekspor konfigurasi; UI kini hanya menerima `maskedToken`/`maskedEnhancerToken` + `isConfigured`. `SettingsModal` tidak lagi mengirim token kosong.
- **Gate header proxy (`961f619`)**: header `X-Forwarded-For`/`X-Real-IP`/`X-Forwarded-Proto` hanya dipercaya bila `TRUST_PROXY=true`, sehingga klien tidak dapat memalsukan IP untuk melewati rate limit atau memaksa flag cookie `secure`. Statistik storage di-scope per pengguna, dan pesan error klien disanitasi via `toClientErrorMessage`.
- **Validasi konten upload (`7fd4772`)**: upload divalidasi berdasarkan **magic bytes**, menolak SVG dan berkas non-gambar; akuntansi rate limit diperbaiki; ekspor base64 dibatasi (50 MB).
- **SSRF guard & batas unduhan**: `downloadRemoteBuffer` di `storage.ts` menolak URL internal/tidak aman dan membatasi unduhan **25 MB**. Header `X-Content-Type-Options: nosniff` ditambahkan.
- **Standarisasi kontrak API (`fa1a06e`)**: respons error kini memakai satu field `error`; `errorMessage` dihapus. Validasi `model` dan `output_format` ditegakkan server-side. Supresi warning SQLite di `next.config.ts` dihapus.
- **Unifikasi helper & hapus kode mati (`1c73732`)**: modul bersama `src/lib/utils.ts` (browser-safe) dipakai server dan client. Tabel `app_settings` beserta `getAppSettings`/`updateAppSettings`/`getUsersCount` dihapus, bersama `cleanupAllUploadFiles` dan `STANDARD_IMAGE_SIZES`.
- **Patch multi-bug (`dabfbe3`)**: perbaikan validasi upload, rate limiter, dan sejumlah bug kebenaran lain di seluruh route dan komponen.
- **Rate limiter (`e74708f` → `1c73732`)**: komit `e74708f` sempat memindahkan rate limiter ke SQLite, namun pada akhir rilis state-nya adalah **in-memory `Map`** dengan pembersihan berkala di `src/lib/rateLimiter.ts`; tabel `rate_limit_attempts` di-drop saat migrasi.
- **Tanpa timeout artifisial (`123e4d0`)**: timeout keras 120 detik pada endpoint generations dan edits dihapus agar request berdurasi panjang (mis. model berlatensi tinggi) tidak diputus prematur.
- **Sesi & integritas data**: sesi invalidasi saat ganti password; `DELETE FROM api_hits WHERE user_id IS NULL` hanya dijalankan sekali saat migrasi; LIKE escaping pada pencarian riwayat.
- **PWA & UI**: `manifest.ts` diperbarui (`background_color` → `#f8fafc`, `orientation` → `any`); `layout.tsx` memakai `lang="id"`.
- **Label & alur UI (`1018844`, `3c7f617`, `bde5041`)**: label "Enhance Prompt" → **"Sempurnakan Instruksi"**; hasil generation dibuka **langsung di tab baru** (modal preview dihapus); urutan tab dan aksi footer pada `SettingsModal` dirapikan.

---

## ⚠️ Perubahan Breaking & Migrasi

- **Tabel lama di-drop otomatis**: `app_settings` dan `rate_limit_attempts` dihapus saat inisialisasi database. Pengaturan global tidak lagi tersedia; gunakan `user_settings` per akun.
- **Field respons API dihapus**: `rawToken` dan `enhancerToken` tidak lagi dikembalikan. Konsumen API harus beralih ke `maskedToken`/`maskedEnhancerToken` dan `isConfigured`.
- **Kontrak error berubah**: respons error memakai field `error` saja; `errorMessage` dihapus dari respons generations/edits.
- **`GET /api/history` tanpa autentikasi kini `401`** (sebelumnya mengembalikan objek kosong dengan status 200).
- **Rate limit per-IP dilewati** kecuali `TRUST_PROXY=true`; rate limit per-akun tetap berjalan.

## 📌 Catatan Rilis

- Rilis ini **tidak** menyertakan perubahan skema yang memerlukan intervensi manual; migrasi tabel lama berjalan otomatis saat aplikasi pertama kali dijalankan.
